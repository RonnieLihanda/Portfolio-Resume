What I do

Work tools already hold the facts: who did what, how long it took, what is late. I connect those tools so the answer reaches the manager without anyone assembling it by hand.

Examples on this site

  • Operations automation for a data team: weekly reports that combine Jira activity with Tempo hours, and reminders that keep the logs complete.
  • Claude skills for proposal and reporting work: tracking and compliance matrices for RFP responses.

How I approach a dashboard

  1. Ask which decision the dashboard supports and who makes it.
  2. Fix the data first: one source for each number, and a rule for missing entries.
  3. Show few measures, each with a clear definition.
  4. Schedule it, so it refreshes without anyone remembering to.
