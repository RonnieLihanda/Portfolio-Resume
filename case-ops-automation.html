The problem

A data team logged its daily work in Jira and Tempo, and every person needed a weekly activity report. Updates were missed, the manager spent time chasing people, and reports were written by hand from ticket comments and time logs.

What I built

Three connected n8n workflows. Each one does a single job, so one can fail without taking the others down.

Activity reminder

Runs on Wednesday, Thursday and Friday. It asks Jira which tickets changed since Monday and finds the people with no activity. A Google Sheets log records who was already reminded, so nobody gets the same message twice. The wording escalates from first reminder to final reminder, with managers copied.

Weekly report with AI drafting

Runs weekly and works through these steps:

  1. Reads the team board through the Jira REST API, including comments and change history.
  2. Matches each ticket to its owner and program, and keeps only tickets with activity this week.
  3. Sends each ticket's comments to an AI model that returns a fixed report structure: activities, accomplishments, issues, risks, support needs, next week and planned leave.
  4. Merges and de-duplicates bullets for each person with code, so the report reads as one piece.
  5. Publishes each report to Confluence, renders a branded PDF, and emails all PDFs to management in one message.

Hours version with Tempo

The same report, plus time tracking. It pulls Tempo worklogs, resolves issue IDs to ticket keys, merges Jira and Tempo records without double counting, and sends a per-person hours summary.

Reliability work

  • The reminder log records who was reminded and when, so the duplicate check works week after week.
  • Reminders go to the actual person, with managers copied.
  • If the report email fails, an alert goes out through the node's error output instead of the failure passing silently.
  • The AI step is told to use only this week's comments and to write "N/A" where the comments are silent, so it does not invent accomplishments.

Stack

n8n, Jira Cloud REST API, Tempo, Confluence API, OpenAI gpt-4.1-mini through the n8n AI Agent node, Google Sheets, SMTP, DocRaptor for PDF rendering, JavaScript in code nodes.
